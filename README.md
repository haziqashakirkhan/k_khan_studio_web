# K_Khan_Studio

> **Photography • Videography • Video Editing**
> **25+ Years of Professional Experience**

A premium, cinematic portfolio and business website for **K_Khan_Studio**, an experienced Pakistani photography and videography studio offering professional visual services for weddings, events, brands, businesses, and documentary projects.

## About

K_Khan_Studio brings more than **25 years of professional experience** in photography, videography, and video production.

The website is designed to showcase the studio's work, services, equipment, packages, and contact options through a clean, cinematic, and professional interface.

The goal is to create an online presence that feels like an **established professional studio**, rather than a typical template or AI-generated website.

## Design Philosophy

The website uses a:

* Cinematic
* Editorial
* Elegant
* Minimal
* Professional
* Warm
* Timeless

visual direction.

The design uses calm, sophisticated tones such as ivory, beige, taupe, charcoal, deep brown, and subtle bronze/gold accents.

The goal is to maintain a **premium photography-studio aesthetic** without excessive gradients, animations, glassmorphism, or generic AI-style UI.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project:

```bash
cd K_Khan_Studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## Deployment

The website can be deployed using platforms such as:

* Vercel
* Netlify
* Firebase Hosting

Make sure all production assets, especially the hero video and portfolio images, are optimized before deployment.
